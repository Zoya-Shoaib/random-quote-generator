# Random Quote Generator

A simple, responsive web app that displays random motivational and inspirational quotes at the click of a button. Built with **HTML**, **CSS**, and **JavaScript**.

## Features
- Generates a new quote each time the "Generate Quote" button is clicked.
- Clean and simple design.
- Responsive layout.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Media Queries)
- JavaScript (DOM Manipulation)
